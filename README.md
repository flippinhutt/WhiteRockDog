# White Rock Dog Rescue website

An unofficial redesign of [whiterockdog.org](https://www.whiterockdog.org/), the site for a Dallas dog rescue. This is a preview, not the rescue's official site.

Preview: https://flippinhutt.github.io/WhiteRockDog/

## Run locally

The site is plain HTML, CSS and JavaScript with no build step or dependencies.

```sh
python3 -m http.server 8765
```

Then open http://localhost:8765.

## Before launch

Remove `<meta name="robots" content="noindex">` from every page. It keeps this preview out of search results.
